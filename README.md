# 乌鹊南飞

第一关「辕门射戟」试玩版（4.3）。建安元年秋，叔叔带着阿鹊困在小沛：白天出城打猎，晚上在营里开饭堂。

**在线玩：** https://chuyuanwritings-max.github.io/wuque-nanfei/

**手机**：横过来玩。左手按住屏幕左边走路，右手按住右下的大圆拉弓（往外拖是瞄准，松手射；不拖就自动瞄最近的猎物）。iPhone 想全屏：Safari 点「分享」→「添加到主屏幕」，从桌面打开。

**电脑**：键盘加鼠标：
- WASD 走路，按住左键拉弓、松手射，空格扑，Shift 慢慢走
- 路上按住 E 开军需箱；1 / 2 换武器
- 晚上按住菜拖到客人身上上菜；按住酒坛拖到客人面前倒酒
- 随时按 Esc 打开菜单（存档、读档、回主页）

存档只存在你自己的浏览器里。
